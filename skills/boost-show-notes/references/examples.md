### Transformations to notice

- *"5 types of apps by Josh and Charles"* + LinkedIn safety URL → **["Power Apps in 2026: Which App Type Should You Actually Use?"](https://www.youtube.com/...) by Charles Sexton and Josh Giles**. - *"Color Cloud workshop... by Scott"* and *"And we have one as well!!"* → two separate entries with **anchor-link URLs into the same workshops page**, one credited to Scott Durow, one to Nick and Ulrikke.
- *Gen Pages…* item kept as plain text — no good canonical URL existed, so just the title remains.
- GitHub usernames decoded: `ToluVictor` → "Tolu Victor", `nickmeron` → "Nir Meron".
- LinkedIn slug `victorsanwoolu` → had no good post URL so the GitHub repo took its place; the Tolu Victor credit came from inspecting the repo owner's full name.
- `(u)` and `(n)` markers stripped.
- `valentinicola` LinkedIn slug → "Nicola Valenti" (the slug reverses surname-first; verified against LinkedIn profile name).
- `youtu.be/i_ZqEKHFuyE` short URL → full `youtube.com/watch?v=...` URL, author "Keegan Chambers" researched from the video page.
- The "Cowork vs Cowork" item had two URLs in OneNote (a LinkedIn safety redirect and the direct vibes.jukkan.com link); the direct link won.

### Transformations to notice

- **Featured section was added entirely from outside OneNote** — Color Cloud as event + Agent Academy landing page. These URLs aren't in the OneNote at all; they came from the conversation framing. The skill should ASK whether a featured section is needed and not invent one.
- *"Resa Dorani"* (a typo in OneNote) → corrected to **"Reza Dorrani"**.
- Title rewritten and emoji added: *"a new way to build Canvas Apps"* → *"A New Way to Build Canvas Apps 🚀 (Power Apps MCP Server)"*.
- *"Cloning Power Pages PAC CLI - Nikita"* → replaced entirely with the **Microsoft Learn PAC CLI reference docs** because that's a more authoritative source than a LinkedIn share. The original LinkedIn URL was dropped.
- An item that wasn't in OneNote at all — **"MCP Apps now available in Copilot chat"** by Deepak Pratinidhi — was added because it came up in the transcript.
- Another Microsoft Learn doc — **"Unify Power Pages authorization..."** — was added in support of the Valentin Gasenko piece, since it documents the official feature his post discussed.
- Microsoft Learn docs have **no `by Author` suffix** — they're official documentation, not personal work.
- Note: *"By Valentin Gasenko"* uses a capital B — that's how it was published. The skill should default to lowercase `by` and not worry about matching this single quirk.

### Transformations to notice

- **Three sections, not just one.** Agent Academy items pulled to the top, Mirko Peters article pulled to the bottom as a Podcast section.
- **Items 1 and 2 in OneNote (Hackathon, Agent Academy Live) had numbers** because that's where the hosts wanted to start the recording. The numbers were tracking *recording* order, but the items still ended up in their own *section* in the published notes. Numbers ≠ section assignment.
- **Item dropped:** the `devblogs.microsoft.com/visualstudio/agent-skills-in-visual-studio/` URL is in OneNote but NOT in the published show notes. Validate against the transcript before dropping; surface a "dropped this — was it discussed?" line in the Review block.
- **URLs hunted down for items that only had descriptive titles in OneNote:**
  - "How to Call Power Automate Flows..." → got a YouTube URL.
  - "Microsoft Copilot Studio | FULL COURSE" → got a YouTube URL.
  - "NEW Workflows Feature..." → got a YouTube URL.
  - "Jonas rapp and xrm fetch xml builder" (a single line) → got a LinkedIn post URL AND the full official title.
  - "Claude Folder Setup by Manthan Patel" → got a `resources.leadgenman.com` URL.
- **`by the Power CAT team`** — team credit, not individual.
- **Microsoft Learn entries (Self-healing, Navigate to and from...) — no `by`**.
- **CoE Starter Kit item:** OneNote had both the Learn link AND a LinkedIn safety redirect; the Learn link won, the title became the LinkedIn post's actual headline ("Microsoft Power Platform Center of Excellence (CoE) Starter Kit transition to Power Platform admin center").
- **Shout out! section dropped entirely.**
- **"Steve built a thing" sub-header dropped**; both Steve items kept.
- The parenthetical *"(Steve was getting whiny that we weren't mentioning him lately 😂)"* dropped.
